    1.1. Introduction

    أهداف المقالة:

    • كتابة تطبيق ويب ثلاثي الطبقات [interface utilisateur, métier, accès aux données]
    • تكوين التطبيق باستخدام Spring IOC
    • كتابة إصدارات مختلفة عن طريق تغيير تنفيذ إحدى الطبقات الثلاث.

    الأدوات المستخدمة:

    • Visual Studio.net للتطوير - انظر الفقرة 3.1 في الملحق؛
    • خادم الويب Cassini للتنفيذ - انظر الفقرة 3.2 في الملحق؛
    • Nunit للاختبارات الفردية – انظر الفقرة 3.4 في الملحق؛
    • Spring للتكامل وتكوين طبقات تطبيق الويب - انظر الفقرة 3.3 في الملحق؛

    على مقياس المبتدئ - المتوسط - المتقدم، يقع هذا المستند في الجزء [intermédiaire-avancé]. ويتطلب فهمه عدة متطلبات مسبقة. يمكن اكتساب بعضها من المستندات التي قمت بكتابتها. وفي هذه الحالة، أقوم بالإشارة إليها. ومن الواضح تمامًا أن هذا مجرد اقتراح وأن القارئ يمكنه استخدام مستنداته المفضلة.

    • لغة VB.net: [مقدمة إلى لغة VB.NET من خلال الأمثلة (2004)]؛
    • البرمجة على الويب بلغة VB.net: [تطوير الويب باستخدام ASP.NET 1.1 (2004)]؛
    • استخدام مكون Spring المسمى IoC: [Spring IoC لـ .NET (2005)]؛
    • التوثيق Spring.net: [Spring.NET | Homepage ]

    يستند هذا المستند إلى الخطوط العريضة لمستند مكتوب بلغة Java [[البنى ثلاثية المستويات وبنى MVC باستخدام Struts وSpring و(2005)] . نقوم في VB.NET ببناء تطبيق الويب MVC ذي الطبقات الثلاث والمكتوب بلغة Java. الفكرة التي نريد توضيحها هنا هي أن منصتي التطوير Java و.NET متقاربتان بما يكفي بحيث يمكن إعادة استخدام المهارات المكتسبة في أحد هذين المجالين في المجال الآخر.

    لا يبدو أن هناك حلاً معترفًا به على نطاق واسع لتطوير MVC وASP.NET. الحل التالي يعتمد على الطريقة التي تم تقديمها في الوثيقة [تطوير الويب باستخدام ASP.NET 1.1 (2004)]. ورغم أن هذه الطريقة تتميز باستخدام مفاهيم شائعة في تطوير J2EE، إلا أنه لا ينبغي النظر إليها إلا على أنها ما هي عليه، c.a.d، أي طريقة من بين طرق تطوير MVC الأخرى. وبمجرد أن تحظى إحدى طرق التطوير MVC في ASP.NET بقبول واسع النطاق، سيكون من الضروري عندئذٍ اعتماد هذه الطريقة. وقد تكون نسخة Spring .NET، التي لا تزال قيد التطوير، الحل الأول في هذا الصدد.

    1.2. تطبيق webarticles

    نقدم هنا عناصر تطبيق ويب مبسط للتجارة الإلكترونية. سيسمح هذا التطبيق لعملاء الويب بما يلي:

    • الاطلاع على قائمة بالمنتجات المستمدة من قاعدة بيانات
    • إضافة بعضها إلى سلة التسوق الإلكترونية
    • الموافقة على سلة التسوق. وسيكون التأثير الوحيد لهذه الموافقة هو تحديث مخزون المنتجات المشتراة في قاعدة البيانات.

    وستكون العروض المختلفة المعروضة للمستخدم كما يلي:

    - العرض "LISTE" الذي يعرض قائمة بالمنتجات المعروضة للبيع
    - العرض [INFOS] الذي يقدم معلومات إضافية عن أحد المنتجات:
    • طريقتا العرض [PANIER] و [PANIERVIDE] اللتان تعرضان محتويات سلة التسوق الخاصة بالعميل
    • عرض [ERREURS] الذي يُبلغ عن أي خطأ في التطبيق

    1.3. البنية العامة للتطبيق

    نرغب في إنشاء تطبيق بهيكل ثلاثي الطبقات على النحو التالي:

    • تتمتع الطبقات الثلاث بالاستقلالية بفضل استخدام الواجهات
    • ويتم تكامل الطبقات المختلفة بواسطة Spring
    • يتم تخصيص مساحات أسماء منفصلة لكل طبقة: web (طبقة UI)، domain (طبقة الأعمال) و dao (طبقة الوصول إلى البيانات).

    سيتبع التطبيق بنية MVC (النموذج - العرض - وحدة التحكم). إذا عدنا إلى مخطط الطبقات أعلاه، فإن بنية MVC تندمج فيه على النحو التالي:

    تتم معالجة طلب العميل وفقًا للخطوات التالية:

    1. يقدم العميل طلبًا إلى وحدة التحكم. وستكون وحدة التحكم هذه في هذه الحالة صفحة .aspx سيُعطى لها دور خاص. فهي تستقبل جميع طلبات العملاء. وهي بمثابة بوابة الدخول إلى التطبيق. وهي تمثل الحرف C في MVC.
    1. يقوم وحدة التحكم بمعالجة هذا الطلب. وللقيام بذلك، قد يحتاج إلى مساعدة من طبقة الأعمال، وهو ما يُسمى بالنموذج M في بنية MVC.
    2. يتلقى وحدة التحكم ردًا من طبقة الأعمال. وقد تمت معالجة طلب العميل. وقد يؤدي ذلك إلى عدة ردود محتملة. ومن الأمثلة الشائعة على ذلك
      • صفحة أخطاء إذا تعذر معالجة الطلب بشكل صحيح
      • صفحة تأكيد في الحالات الأخرى
    3. يختار وحدة التحكم الرد (= العرض) الذي سيتم إرساله إلى العميل. وغالبًا ما يكون هذا الرد عبارة عن صفحة تحتوي على عناصر ديناميكية. وتقوم وحدة التحكم بتزويد العرض بهذه العناصر.
    4. يتم إرسال العرض إلى العميل. وهذا هو الحرف V في MVC.

    1.4.3.1. الفئة [Article]

    الفئة التي تُعرّف المقالة هي التالية:

    Imports System

Namespace istia.st.articles.dao

    Public Class Article

         ' الحقول الخاصة
        Private _id As Integer
        Private _nom As String
        Private _prix As Double
        Private _stockactuel As Integer
        Private _stockminimum As Integer

         ' معرف العنصر
        Public Property id() As Integer
            Get
                Return _id
            End Get
            Set(ByVal Value As Integer)
                If Value <= 0 Then
                    Throw New Exception("Le champ id [" + Value.ToString + "] est invalide")
                End If
                Me._id = Value
            End Set
        End Property

         ' اسم المنتج
        Public Property nom() As String
            Get
                Return _nom
            End Get
            Set(ByVal Value As String)
                If Value Is Nothing OrElse Value.Trim.Equals("") Then
                    Throw New Exception("Le champ nom [" + Value + "] est invalide")
                End If
                Me._nom = Value
            End Set
        End Property

         ' سعر المنتج
        Public Property prix() As Double
            Get
                Return _prix
            End Get
            Set(ByVal Value As Double)
                If Value < 0 Then
                    Throw New Exception("Le champ prix [" + Value.ToString + "] est invalide")
                End If
                Me._prix = Value
            End Set
        End Property

         ' المخزون الحالي للمنتج
        Public Property stockactuel() As Integer
            Get
                Return _stockactuel
            End Get
            Set(ByVal Value As Integer)
                If Value < 0 Then
                    Throw New Exception("Le champ stockActuel [" + Value.ToString + "] est invalide")
                End If
                Me._stockactuel = Value
            End Set
        End Property

         ' الحد الأدنى لمخزون المنتج
        Public Property stockminimum() As Integer
            Get
                Return _stockminimum
            End Get
            Set(ByVal Value As Integer)
                If Value < 0 Then
                    Throw New Exception("Le champ stockMinimum [" + Value.ToString + "] est invalide")
                End If
                Me._stockminimum = Value
            End Set
        End Property

         ' الشركة المصنعة الافتراضية
        Public Sub New()
        End Sub

         ' الشركة المصنعة مع الخصائص
        Public Sub New(ByVal id As Integer, ByVal nom As String, ByVal prix As Double, ByVal stockactuel As Integer, ByVal stockminimum As Integer)
            Me.id = id
            Me.nom = nom
            Me.prix = prix
            Me.stockactuel = stockactuel
            Me.stockminimum = stockminimum
        End Sub

         ' طريقة تحديد المنتج
        Public Overrides Function ToString() As String
            Return "[" + id.ToString + "," + nom + "," + prix.ToString + "," + stockactuel.ToString + "," + stockminimum.ToString + "]"
        End Function
    End Class
End Namespace

    توفر هذه الفئة:

    1. منشئًا يسمح بتحديد المعلومات الخمس الخاصة بالمقالة: [id, nom, prix, stockactuel, stockminimum]
    2. خصائص عامة تتيح قراءة وكتابة المعلومات الخمس.
    3. التحقق من صحة البيانات التي يتم إدخالها في المقالة. في حالة وجود بيانات خاطئة، يتم إلقاء استثناء.
    4. طريقة toString تتيح الحصول على قيمة عنصر ما في شكل سلسلة أحرف. وغالبًا ما يكون ذلك مفيدًا لتصحيح أخطاء التطبيق.

    1.4.4.3. الفئة [Panier]

    تمثل الفئة [Panier] مجموعة عمليات الشراء الخاصة بالعميل:

    Namespace istia.st.articles.domain

Public Class Panier

     ' الحقول الخاصة
    Private _achats As New ArrayList
        Private _totalPanier As Double = 0

     ' الشركة المصنعة الافتراضية
    Public Sub New()
    End Sub

     ' قائمة المشتريات
    Public ReadOnly Property achats() As ArrayList
        Get
            Return _achats
        End Get
    End Property

     ' إجمالي المشتريات
    Public ReadOnly Property totalPanier() As Double
        Get
            Return _totalPanier
        End Get
    End Property

     ' الطرق
    Public Sub ajouter(ByVal unAchat As Achat)
         ' يتم البحث عما إذا كان المشتريات موجودًا بالفعل
        Dim iAchat As Integer = posAchat(unAchat.article.id)
        If iAchat <> -1 Then
             ' تم العثور عليه
                Dim achatCourant As Achat = CType(_achats(iAchat), Achat)
            achatCourant.qte += unAchat.qte
        Else
             ' لم يتم العثور عليه
            _achats.Add(unAchat)
        End If
         ' زيادة إجمالي سلة التسوق
        _totalPanier += unAchat.totalAchat
    End Sub

     ' إزالة منتج من سلة التسوق
    Public Sub enlever(ByVal idAchat As Integer)
         ' البحث عن المنتج
            Dim iachat As Integer = posAchat(idAchat)
         ' إذا تم العثور عليه، يتم حذفه
        If iachat <> -1 Then
                Dim achatCourant As Achat = CType(_achats(iachat), Achat)
             ' يتم حذف المنتج من سلة التسوق
            _achats.RemoveAt(iachat)
             ' يتم خصم المبلغ من إجمالي سلة التسوق
            _totalPanier -= achatCourant.totalAchat
        End If
    End Sub

    Private Function posAchat(ByVal idArticle As Integer) As Integer
         ' البحث عن عملية شراء في قائمة المشتريات
         ' إرجاع ترتيبه في القائمة أو -1 في حالة عدم العثور عليه
        Dim achatCourant As Achat
        Dim trouvé As Boolean = False
        Dim i As Integer = 0
            While Not trouvé AndAlso i < _achats.Count
                 ' العملية الحالية
                achatCourant = CType(_achats(i), Achat)
                 ' مقارنة مع المنتج المطلوب
                If achatCourant.article.id = idArticle Then
                    Return i
                End If
                 'عملية الشراء التالية
                i += 1
            End While
             ' لم يتم العثور عليه
            Return -1
    End Function

     ' وظيفة الهوية
    Public Overrides Function ToString() As String
        Return _achats.ToString
    End Function
End Class

End Namespace

    • تحتوي الفئة [Panier] على الخصائص والطرق التالية: 
    ReadOnly Property achats() As ArrayList
    قائمة مشتريات العميل - قائمة العناصر من النوع [Achat]

    تضيف عملية شراء إلى قائمة المشتريات

    حذف عملية الشراء الخاصة بالمنتج idAchat

    المبلغ الإجمالي لمشتريات سلة التسوق
    Function ToString() As String
    إرجاع سلسلة معرف سلة التسوق
    • الطريقة [posAchat] هي طريقة مساعدة تسمح بالحصول على الموضع في قائمة المشتريات لمشتريات محددة برقم المنتج الذي تم شراؤه. تُدار قائمة المشتريات بحيث لا يشغل المنتج الذي تم شراؤه عدة مرات سوى موضع واحد في القائمة. وبالتالي، يمكن تحديد عملية الشراء برقم المنتج الذي تم شراؤه. تُرجع الطريقة [posAchat] القيمة -1 إذا كانت عملية الشراء المطلوبة غير موجودة.
    • تقوم الطريقة [ajouter] بإضافة عملية شراء جديدة إلى قائمة المشتريات. وهذا يعني إما إضافة إدخال جديد إلى قائمة المشتريات إذا لم يكن المنتج المشترى موجودًا بالفعل في القائمة، أو زيادة الكمية المشتراة إذا كان موجودًا بالفعل.
    • تسمح الطريقة [enlever] بإزالة عملية شراء محددة برقم من قائمة المشتريات. إذا لم تكن عملية الشراء موجودة، فإن الطريقة لا تصدر أي رسالة ولا تقوم بأي إجراء.
    • يتم الحفاظ على مبلغ المشتريات [totalPanier] مع عمليات إضافة وحذف المشتريات.

    لننظر إلى طريقة العرض [ERREURS] التي تعرض قائمة بالأخطاء:

            Dim parameters() As String = {"urlMain", "urlErreurs", "urlInfos", "urlListe", "urlPanier", "urlPanierVide"}
            Dim erreurs As New ArrayList

            Dim param As String

                 ' قراءة من ملف التكوين
                param = ConfigurationSettings.AppSettings(parameters(i))
                If param Is Nothing Then
                     ' تسجيل الخطأ
                    erreurs.Add("Paramètre [" + parameters(i) + "] absent dans le fichier [web.config]")
                Else
                     ' يتم تخزين المعلمة في التطبيق
                    Application.Item(parameters(i)) = param
                End If
            Next
             ' هل توجد أخطاء؟
            If erreurs.Count = 0 Then
                 ' يتم إنشاء كائن IArticlesDomain للوصول إلى طبقة الأعمال
                Dim contexte As IApplicationContext = CType(ConfigurationSettings.GetConfig("spring/context"), IApplicationContext)

                    articlesDomain = CType(contexte.GetObject("articlesDomain"), IArticlesDomain)
                     ' يتم تخزين الكائن في التطبيق
                    Application.Item("articlesDomain") = articlesDomain
                Catch ex As Exception
                     ' يتم تخزين الخطأ
                    erreurs.Add("Erreur lors de la construction de l'objet d'accès à la couche métier [" + ex.ToString + "]")
                End Try
            End If
             ' يتم وضع الأخطاء في التطبيق
            Application.Item("erreurs") = erreurs
             ' تنتهي العملية في حالة وجود أخطاء
            If erreurs.Count <> 0 Then Return

            Dim urlMain As String = CType(Application.Item("urlMain"), String)
